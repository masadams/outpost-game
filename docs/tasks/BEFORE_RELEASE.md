# Before an official release

Things deliberately left easy or fast for testing, to change before a release.

- **Research takes longer.** Research is fast now so it can be tested. Before release, early research should take
  minutes and later research longer still. Tune with the full story pacing in mind (`docs/STORY.md`).
- **Run the whole browser suite** (`npm run test:browser`), not just the specs for the latest change.
